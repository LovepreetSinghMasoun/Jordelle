# Jordelle 📚💘

**Find Your Next Love Story** — an AI-powered romance book recommendation site that matches readers with their perfect book based on mood, tropes, and vibe.

🔗 **Live site:** [jordelle.netlify.app](https://jordelle.netlify.app)

## Overview

Jordelle helps romance readers discover their next favorite book by asking what they're in the mood for — a trope, a feeling, or just a vague "surprise me" — and returning tailored recommendations.

## Features

- 🎭 **Trope-based browsing** — Enemies to Lovers, Slow Burn, Friends to Lovers, Dark Romance, Fantasy, Sports, College, and more
- ❤️ **Mood picker** — Sweet, Angst, Spice, Comfort, Funny, Adventure
- ✨ **"Surprise Me"** — instant recommendation for indecisive readers
- 🤖 **AI-powered matching** — recommendations get smarter the more you share
- 📖 **Curated library** — access to a large catalog of romance titles
- 📱 **Responsive design** — clean, mobile-friendly UI

## Pages

| Page | Path | Description |
|------|------|--------------|
| Home | `/` | Landing page with hero section, trope shortcuts, and mood input |
